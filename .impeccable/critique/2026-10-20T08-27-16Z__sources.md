## 优先改进动作（等待用户选择）

### 1. P1 插件检查形成可执行闭环

已确认：正式页面显示“尚无插件兼容检查结果”，仅有管理插件按钮。`Sources/GuardianPanel.swift:197` 至 260，只有候选结果提供重新检查当前引擎。无结果成因未诊断，不归因为服务故障。

建议：提供检查当前引擎/重试，区分未检查、检查中、失败和有结果；展示范围、时间、影响；已确认冲突行显示建议和管理入口，技术依赖折叠。保留上次结果并标记过期。复用已有检查方法，不新增独立检查管道。诊断结论保持谨慎：无法确认不等于不兼容。桌面端不直接安装依赖、禁用或移除插件；后者属于另一个需要协议和安全预检的功能。

对应技能动作：impeccable clarify / harden。

### 2. P2 将引擎任务集中到“恢复与版本”

已确认：引擎通道和立即检查位于 `Sources/SettingsView.swift:175` 起；已装版本和版本管理在 `Sources/GuardianPanel.swift:306` 起。完成一次版本决策需要跨页。

建议：在恢复与版本放置当前引擎、所选通道、检查结果、更新和已保留版本，桌面端设置仅保留快捷键、快速提问默认值、余额。原菜单快捷入口指向同一任务，而不是复制另一份表单。保留现有预检、确认、回退和会话格式保护，不改更新规则。

对应技能动作：impeccable layout / distill。

### 3. P2 重新编排概览，不用卡片填空

已确认：960×572 浅色实图主体只有约 90px 高状态卡，其余大面积空白；`Sources/GuardianPanel.swift:174` 起与截图相符。

建议：保留一个状态区域和一个打开工作区主操作；下方用紧凑行显示当前引擎/通道、最近一次有效检查及真正需处理的问题，正常时不显示一组绿灯或假数据。诊断失败时就地显示下一步，不只让人记住去另一页。运行健康、网页可用、插件检查是不同事实，不合并成虚假的全绿。

对应技能动作：impeccable layout / polish。

### 4. P2 快速提问回归轻量入口

源码确认、实图未验：`Sources/QuickPromptPanel.swift:112` 起有星光和背景渐变；232 起新会话目录、模型、力度与提问框同屏；固定 680×560。不能断言当前已裁切或焦点失效。

建议：首屏优先目标会话、提问框、发送；目录必须始终可识别，显示简短路径摘要，编辑目录/模型/力度可收进可展开选项。已有会话列表较长时提供搜索，原快捷键、草稿和成功交接保留。去掉通用星光与装饰渐变，使用统一原生图标或鲸鱼。

对应技能动作：impeccable distill / polish。

### 5. P1 补辅助标签，P3 清理技术噪声

建议：补阈值名称和单位、快照选中状态、引擎删除动作名称，做完整键盘和 VoiceOver 验证。恢复页 `restart · completed`、毫秒时间改成中文动作和本地短时间；完整诊断仍可展开复制。不得把重要错误消息截掉而不给详情。

对应技能动作：impeccable audit / clarify / polish。
