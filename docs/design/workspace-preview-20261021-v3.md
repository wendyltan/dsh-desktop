## 配色策略

白色阅读区、极浅冷蓝侧栏与窗口层次，搭配 DeepSeek 蓝系主色 `#4D6BFE`；这是本稿选用的品牌风格化颜色，不宣称是经核对的官方唯一品牌色。主文字为 `#1F2A44`，次要文字使用有对比度的冷蓝灰。

蓝色承担品牌标记、新建会话、会话选中、发送及焦点等明确职责；技术感来自精确线性图标、冷色层次、清晰对齐和轻边界，不增加光晕、霓虹网格、装饰性状态、数字面板或动画。

保留 v2 的布局、文字、字号、间距、原生式一体圆角输入区和模型/权限含义。HTML 结构不改，不把三个矩形下拉框加回来。v1/v2 原稿保留。

本目录中的鲸鱼 SVG 仅将现有资源的颜色改为蓝色，轮廓路径不变。产品代码、正式应用、引擎和用户偏好均不在编辑范围。
