FORM：现有产品品牌约束下的一套主界面设计提案，代码绘制并本地渲染；不是新的品牌世界，也不进行随机概念竞赛。样稿用虚构任务和会话，不显示用户真实内容。没有已批准的 comp，用户将审核本次输出的图。

## 范围与实现边界

- **已存在的能力**：会话导航、侧栏收起/拖动与窄屏响应、会话/轨迹、工作区插件管理、模型/力度/权限选择。样稿不新增业务能力，也不自动批准权限。
- **公开但影响范围大的能力**：theme 的 token 覆盖会影响整个工作区。仅有此能力不足以实现本图所有布局。
- **仍需集成验证，可能需要上游配合**：侧栏内部会话行/分组结构、标题区排布、输入区参数独立分组、首页文案。本次复查发现上游有 `sidebar.workspaces`、`conversation.composer`（chain）和 `conversation.composer.bar` 等 slot 声明；但单一席位的所有权、已有子席位的复用，以及 composer 的包私有注入均构成约束，不能把“存在 slot”当作“整套布局已可安全替换”。现桌面桥尚未实现这些布局。批准后先验证官方组合路径，不足时再明确上游接口改动；不能直接改已安装引擎包、依赖哈希 CSS 类名或做 DOM 文本替换。
- “思考力度”展示用示例标签；实现必须保留模型目录的原始 ID 和取值，不能把不同模型的等级硬映射为同一含义。
- 浅色外观、加载/失败/审批等产品全状态不是本轮效果图的已验收范围；未来实现必须保留，不能因本图省略而删除。
