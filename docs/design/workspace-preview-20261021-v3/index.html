工具维护

梳理本地工具的维护流程

虚构会话，仅供设计评审今天，10:42

帮我把本地工具的维护事项整理成每月检查流程，重点关注备份、更新和恢复验证。

DeepSeek

建议每月按“先确认能恢复，再决定是否更新”的顺序检查，最后记录结果。这样可以先保障回退条件，再处理版本变化。

每月维护流程

1

核对备份

确认配置快照时间与内容范围，并检查会话目录可读。发现缺失时先补齐备份。

2

检查更新

记录当前引擎版本和通道，查看插件兼容结果；更新前保留可用回退版本。

3

验证恢复

在测试环境恢复快照，确认配置可读、工作区能打开，并记录验证日期与结果。

“备份完成”说明有副本；“恢复成功”才说明副本可用。
